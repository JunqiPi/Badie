# 给宣传负责人（agent）的交接说明

> 2026-10-22 写，2026-10-24 更新（App 已提交审核、新功能、商店页文案）。你负责 Badie 的宣传：Instagram、小红书、TikTok，以及 Reddit、Facebook 群这类社区。
> 产品和网站由另一个对话里的工程 agent 负责。需要改网站、加功能、出素材图时，请用户转达过去。
> 仓库是公开的：https://github.com/JunqiPi/Badie 。宣传口径以 `Badie-iOS/docs/STORY.md` 为准，本文和它冲突时，先问用户。

## 1. 和用户合作的规矩

- **用中文和用户交流**。面向美国的帖子用英文写，面向华人的用中文。
- **对外的动作先问**：发帖、评论、私信、注册账号、绑定第三方工具、花钱，每一项都先给用户看草稿或方案，用户同意了再做。用户明确说“这类以后不用问”之后才可以直接做。
- **密钥、密码、令牌不要贴到聊天里**，让用户自己填到对应平台的设置里。不要在任何地方公开用户的私人邮箱。
- **用户对调研的要求（原话）**：“做调研的时候，注意分辨营销与事实。不能只看官方发布的信息，更关注实际用户的感受（例如社交媒体上）。科研 paper 例外，如果是科研 paper 成分证明可以额外加分。但注意不要过于悲观，没有明确 paper，只要产品受到广泛认可，也可以视为合理。”
- **用户的风格**：话要短，不要堆解释。App 里一屏一句话，解释放在网站和商店页。给方案时直接给推荐，不要列一长串选项。

## 2. Badie 是什么（只说这些已经做到的）

- **一句话**：不用自己开口找人，Badie 按水平帮你找羽毛球球友。免费。
  英文：No need to ask strangers for a game. Badie finds badminton players at your level for you. Free.
- **口号**（App 欢迎页和网站首页同一句）：羽毛球搭子？就在今日。 / Badminton buddy? Find one today.
- **怎么用**：告诉它你什么时候有空、能去哪些球馆，它帮你匹配水平相近的人，双方都确认才成局。
- **功能**：
  - 定级：2 分钟问卷，1–9 级（每级再分 −、标准、+）。打完球双方确认赛果，和你打过的人帮忙校准。7–9 级要交比赛成绩等证明，管理员审核。
  - 项目：单打、双打、男双、女双、混双。男女等级分开算。
  - 临时局：只找现在就有空的人。
  - 附近球局：订了场地缺人，发出来让附近的人加入。
  - 球群：每周固定时间、固定球馆，报名和候补。
  - 靠谱：爽约和临时取消会被记录。同场多数人说没来、又没签到才算爽约；180 天内第 1 次警告，第 2 次 7 天不能约球，第 3 次永久不能约球，48 小时内可以申诉。资料页显示近 180 天的爽约次数。
  - 加球友：每人有“昵称#编号”，重名也能精确搜到；还有加球友链接和二维码（`badie.rsvp/add/…`），当面一扫就能加。
  - 照片头像：注册时就能选照片，网页上也能传。
  - 排行榜（可以按球馆筛选）、挑战、胜率。
  - 球馆目录：2,772 家球馆，覆盖美国、英国、香港、日本、马来西亚、新加坡、台湾。数字会变，以 https://badie.rsvp/courts/ 为准。
  - 界面有 10 种语言：英文、简体中文、繁体中文、日文、韩文、印尼文、马来文、泰文、越南文、印地文。
- **隐私**：球友只能看到昵称、水平和头像，看不到联系方式。位置只用来找附近的球馆，不保存。
  **不能说“位置不离开你的手机”**：搜附近时坐标会发给服务器，只是不保存。
- **价格**：全部免费，没有广告，也没有付费版。
- **在哪用**：网页 https://badie.rsvp 已经上线，任何浏览器都能用。iPhone App 1.0 **2026-10-24 已提交 App Store 审核**，选的是手动发布：审核通过后用户自己点发布才上架。
  上架前所有帖子的落地页都用网站，**不要承诺上架日期**，也不要说“已经上架”。上架后工程 agent 会在网站加下载按钮，用户会把 App Store 链接告诉你。
  上架地区：中国大陆以外的全部国家和地区；Apple 芯片的 Mac 也能装。

## 3. 不能说的

- 不报用户数，也不暗示人多。不说“最大”“第一”“最火”“最好用”。
- 不说“已经覆盖欧洲”：欧洲目前只有英国的球馆。可以说“我们的**目标**是让美国和欧洲打羽毛球的人更多”。
- 不编造用户评价、截图里的对话或数据。真实球友的原话，征得同意后才能用。
- 不说“安卓 App”：目前只有网页和 iPhone。

## 4. 品牌素材

- **名字**：Badie。单搜 “Badie” 会和人名等撞车，所以宣传、简介、标签里统一写 **Badie badminton** / **Badie 羽毛球**，链接写 `badie.rsvp`。
- **故事**（最有说服力，请用户用第一人称“我”来讲）：创始人一开始不敢在球馆里找陌生人，也不好意思在网上约；约到了也不知道对面什么水平。于是做了 Badie 来替你找人，并且按水平配。另外两个常见场景：固定球友临时有事，以及刚搬到新城市谁也不认识。
- **现成文案**：STORY.md 里有英文短帖、中文小红书帖和 15 秒短视频脚本，可以直接改用。

## 5. 平台接入的现实情况（2026-10 查过，用之前再核实一遍）

- **Instagram**：
  - 用 API 发帖要专业账号（Business 或 Creator），个人账号不行。
  - 用 Instagram 登录的那条接入方式不需要 Facebook 主页，权限叫 `instagram_business_content_publish`。
  - 图片和视频要先放在公开网址上。
  - 每个账号 24 小时内能用 API 发的帖数有上限。文档里有 100、50、25 几种说法，以账号实际返回的 `content_publishing_limit` 为准。
  - 文档：https://developers.facebook.com/docs/instagram-platform/content-publishing
- **TikTok**：Content Posting API 没通过 TikTok 审核时，发出去的视频只能自己可见。要公开发布，得先提交审核。审核时间网上说 2–6 周，官方没写，未核实。
  - 文档：https://developers.tiktok.com/doc/content-posting-api-reference-direct-post
- **小红书**：没找到官方给个人开放的发笔记接口。网上那些模拟登录、指纹浏览器批量发帖的工具违反平台规则，有封号风险，**不要用**。小红书由你写好文案和配图，用户自己手动发。
- **更省事的做法**：Buffer、Later、Metricool 这类排期工具已经和 Instagram、TikTok 官方对接，比自己开发接口快。先比较价格和免费额度，给用户推荐一个。
- **一律不做**：买粉、买赞、刷评论；开小号自问自答；批量自动私信或评论；冒充普通用户推荐自己。找博主合作要按 FTC 规定标明 `#ad` 或“合作”。
- **社区**：Reddit（r/badminton、各城市的版）和 Facebook 球友群大多限制自我推广。发之前先看版规，开头说明“这是我自己做的”，先在社区里正常交流，再发自己的东西。

## 6. 宣传也是在做 SEO 和 AEO

- 搜索引擎和 AI（ChatGPT、Gemini、Perplexity）现在几乎找不到 Badie：域名是新的，网上也还没人提到它。
- 网站这边已经开放给所有爬虫，加了结构化数据、站点地图和常见问题。Search Console 和 Bing 的提交由用户来做。
- 剩下的要靠站外：Ahrefs 统计了 7.5 万个品牌，和品牌出现在 Google AI 回答里关系最大的，是这个品牌在网上被提及的次数（相关系数 0.664），比外链更重要。来源：https://ahrefs.com/blog/ai-overview-brand-correlation/
- 所以每个帖子、简介、回答里都写上 **Badie badminton** 和 **badie.rsvp**。在 Reddit 这类 AI 常引用的地方，认真回答“怎么找球友”“XX 城市哪里打球”这类真实问题，比发广告有用。
- **建好账号后，把各平台主页的网址发给用户**，让工程 agent 加进网站首页的 `sameAs`（让搜索引擎知道这些账号和网站是同一个品牌）。
- 网站目前**没有任何访问统计**，隐私政策也写了不用统计和广告追踪。想看哪个渠道带来了用户，需要用户先决定要不要加不追踪个人的统计（比如 Cloudflare Web Analytics），并且先改隐私政策。在那之前，可以在注册后问“你从哪里知道 Badie 的”，这一步也要让工程 agent 来做。

## 7. 建议的第一步

1. 问用户：已经有哪些账号？想先做哪个市场（美国英文、美国华人，还是马来西亚、新加坡）？有没有预算？
2. 查各平台 `badie`、`badiebadminton`、`badie.rsvp` 这几个账号名能不能注册，给用户推荐一套统一的账号名、头像（用 Logo）、简介和链接。
3. 写出前两周的内容计划，每个平台 3–5 条草稿，附上配图需求。图需要的话找工程 agent 出，用网站的颜色和字体。用户同意后再发。
4. 每周给用户一句话总结：发了什么、哪条反应最好（看点赞、收藏、评论里的原话）、下周做什么。
